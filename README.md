# CV RAG Chatbot

A **Retrieval-Augmented Generation (RAG)** chatbot that answers questions exclusively from the content of an uploaded CV (PDF or DOCX). Built with **Gemini 2.5 Flash**, **FAISS**, and **Streamlit** — no LangChain or LlamaIndex, just clean custom Python.

---

## Features

- Upload any CV in **PDF or DOCX** format
- Semantic search over CV content using **FAISS** vector store
- Answers generated by **Google Gemini 2.5 Flash**
- Refuses to answer questions unrelated to the CV (prompt-enforced grounding)
- Persistent **chat history** within the session
- Fully local embeddings — no external embedding API needed

---

## Architecture

```
CV File (PDF/DOCX)
        │
        ▼
  Text Extraction        ← PyMuPDF (PDF) / python-docx (DOCX)
        │
        ▼
  Text Cleaning          ← Normalize whitespace
        │
        ▼
  Chunking               ← 300-word chunks, 50-word overlap
        │
        ▼
  Embeddings             ← all-MiniLM-L6-v2 (SentenceTransformers)
        │
        ▼
  FAISS Index            ← IndexFlatL2, exact L2 search
        │
   User Question
        │
        ▼
  Query Embedding        ← same SentenceTransformer model
        │
        ▼
  Top-3 Retrieval        ← FAISS nearest-neighbour search
        │
        ▼
  Prompt Construction    ← Inject CV chunks + strict grounding instruction
        │
        ▼
  Gemini 2.5 Flash       ← Generate answer
        │
        ▼
  Streamlit Chat UI      ← Display response
```

## Tech Stack

| Component | Library / Model |
|-----------|----------------|
| Frontend | [Streamlit](https://streamlit.io/) |
| LLM | Google Gemini 2.5 Flash (`google-generativeai`) |
| Embeddings | `all-MiniLM-L6-v2` via `sentence-transformers` |
| Vector Store | FAISS (`faiss-cpu`) |
| PDF Parsing | PyMuPDF (`fitz`) |
| DOCX Parsing | `python-docx` |

## Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/444maxj/cv-rag-chatbot.git
cd cv-rag-chatbot
```

### 2. Create a virtual environment

```bash
python -m venv venv
# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Set up your Gemini API key

Create a `.env` file in the project root:

```env
GEMINI_API_KEY=your_api_key_here
```

> Get your free API key at [Google AI Studio](https://aistudio.google.com/app/apikey).

### 5. Run the app

```bash
streamlit run app.py
```

Open your browser at `http://localhost:8501`.

## How to Use

1. Click **Browse files** and upload a CV (`.pdf` or `.docx`)
2. Wait for the indexing spinner to complete
3. Type any question about the CV in the chat input
4. The bot answers using only information found in the document

## Configuration

You can tweak these parameters directly in `app.py`:

| Parameter | Default | Description |
|-----------|---------|-------------|
| `chunk_size` | `300` | Words per chunk |
| `overlap` | `50` | Overlapping words between chunks |
| `k` | `3` | Number of chunks retrieved per query |
| LLM model | `gemini-2.5-flash` | Gemini model used for generation |
